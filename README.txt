PORTFOLIO PROFESSIONNEL — DIEYE MOUSSA & eConf Numérique & Conférence

Fichiers :
- index.html : portfolio personnel avec expertises, logo eConf, boutons de contact et QR dynamique
- style.css : design professionnel responsive bleu nuit / bleu électrique
- logo-econf-numerique-conference.png : logo fourni eConf avec fond transparent
- Dieye-Moussa.vcf : fiche contact téléchargeable
- README.txt : guide de publication

QR CODE :
Le QR dans la page est généré automatiquement à partir de l'URL réelle quand le site est publié. Pour imprimer le QR sur une carte physique, attendez d'avoir choisi le domaine et publié le portfolio, puis générez un QR haute qualité depuis l'URL HTTPS finale. Gardez cette URL stable.

PUBLICATION :
1. Choisir et acheter un domaine personnel (ex. dieyemoussa.sn, dieyemoussa.com ou autre nom disponible).
2. Choisir un hébergement web statique.
3. Téléverser index.html, style.css, logo-econf-numerique-conference.png et Dieye-Moussa.vcf dans le dossier public.
4. Activer HTTPS/SSL.
5. Tester téléphone, WhatsApp, e-mail, téléchargement VCF et lien vers econfevents.com sur mobile.
6. Générer le QR définitif depuis l'URL HTTPS publiée, l'imprimer sur la carte et tester le scan avant de lancer le tirage.

À compléter si souhaité : domaine définitif, liens de réseaux sociaux, projets/réalisations, diplômes et adresse professionnelle.
